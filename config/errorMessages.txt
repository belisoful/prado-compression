; Error messages for belisoful/prado-compression.
;
; Format, as parsed by Prado\Exceptions\TException::translateErrorMessage():
;
;     message_key		= An ICU MessageFormat pattern; {0} {1} are the exception arguments.
;
; Blank lines are ignored, and a line starting with '#' or ';' is a comment.  The package's
; composer.json registers this file through extra.prado.error-messages, so Prado loads it for
; every application; TException::addMessageFile(__DIR__ . '/errorMessages.txt') registers it by
; hand.  A localized sibling named errorMessages-<lang>.txt is preferred automatically when one
; exists.  An unregistered key still works — the exception carries the key itself as its
; message — so registration affects readability, not behavior.
;
; A message is formatted with \MessageFormatter, which quotes literal text with apostrophes:
; an apostrophe next to a brace is doubled, so ''{0}'' renders the argument in single quotes,
; while '{0}' renders the literal text {0}.  An apostrophe elsewhere, as in "can't", is literal.
;
; The codecs also raise Prado\Exceptions\TIOException from the core base class and trait they
; build on; those keys are defined in the framework's own messages.txt:
;
;     builtincompressor_extension_required	  (TBuiltinCompressor)
;     builtincompressor_compress_failed		  (TBuiltinCompressor)
;     builtincompressor_decompress_failed	  (TBuiltinCompressor)
;     clicompressor_command_missing			  (TCliCompressorTrait)
;     clicompressor_process_failed			  (TCliCompressorTrait)
;     clicompressor_command_failed			  (TCliCompressorTrait)
;
; Do not restate a core key here.  A registered file is read after the framework's messages.txt
; and overrides it, so a duplicate would silently replace the framework text.  Add a key below
; only when this package raises it itself.
